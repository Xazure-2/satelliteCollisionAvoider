# Reports

**Start with [model_development.md](model_development.md).** It explains the final system (the final-tier model and the probability layer on top of it), the headline results, and every experiment that led there. The other files hold detailed tables and background.

| File | What it is | Kind | Status |
|---|---|---|---|
| [model_development.md](model_development.md) | The full story: final system, results, all experiments, decisions, limitations | Hand-written | **Current, main document** |
| [final_tier_report.md](final_tier_report.md) | Final-tier experiments: candidate table, selection, CV confusion matrix, **holdout result** | Generated by `python scripts/train_final_tier.py` | Current |
| [tier_probability_report.md](tier_probability_report.md) | Calibration of P(Safe/Elevated/Critical): CV and holdout scores, reliability bins | Generated by `python scripts/train_tier_probability.py` | Current |
| [final_tier_ensembles.md](final_tier_ensembles.md) | Ensembles, stacking, nested hyperparameter search and row-level Pc features (none beat the selection) | Generated by `python -m src.final_tier_ensembles` | Current (research) |
| [experiment_v2.md](experiment_v2.md) | Row-level experiment that selected the per-message Pc model used in the dashboard | Generated by `python -m src.experiment_v2` | Current (dashboard Pc) |
| [literature_review.md](literature_review.md) | Prior work (ESA Kelvins challenge, CDM studies, stacking, nested CV, missing data) and what we took from it | Hand-written | Current |
| [eda_summary.md](eda_summary.md) | Data audit and frozen event split, written before any model was trained | Generated by the EDA notebook (`python scripts/run_eda.py`) | Pre-modelling record |
| [archive/model_report.md](archive/model_report.md) | First modelling pass (M3, row-level regression) | Generated by the historical `scripts/train.py` (now blocked by its holdout ledger) | **Superseded**, kept for the audit trail |

Generated files are overwritten when their command reruns; edit the generator, not the file. `./run_all.sh` regenerates the current reports except the research ones (add `--research`).
